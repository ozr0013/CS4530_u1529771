# In-Class Practice 7: Designing & Applying a Theme

Custom Material 3 "Ocean" theme applied to the `ThemePractice` project
(see [`../ThemePractice`](../ThemePractice)).

- **Palette:** tonal-spot scheme from seed `#1B6D8C` (primary `#166683`,
  secondary `#4D616C`, tertiary `#5E5A7D`), with full light and dark schemes in
  `ui/theme/Color.kt`.
- **Applied in:** `ui/theme/Theme.kt`. Dynamic color is off so the custom palette is used
  instead of wallpaper colors.
- **Screen:** the top app bar uses `primary`/`onPrimary` and the task card uses
  `secondaryContainer`.
